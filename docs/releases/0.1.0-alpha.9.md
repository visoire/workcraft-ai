## WorkCraft AI 0.1.0-alpha.9 (pre-release)

A local-first AI chat and multi-agent desktop app in Rust. Talk to Ollama or your own hosted models, let them read your files, call MCP tools and drive the Craft apps on your computer.

> **Alpha.** Expect bugs. Windows 11 is the only verified platform; macOS and Linux are untested. The binaries are not code-signed (Windows SmartScreen may warn). Settings and data formats can change between alphas.

### Download

| File | What |
| :--- | :--- |
| `WorkCraft.exe` | the desktop app |
| `WorkCraft-CLI.exe` | terminal chat, headless engine and MCP server (`workcraft-cli mcp`) |
| `SHA256SUMS.txt` | checksums; compare them with `Get-FileHash` before you run the files |

Add a key in **Settings > Providers** (or set `DEEPSEEK_API_KEY`, `OPENAI_API_KEY`, `ANTHROPIC_API_KEY`) or start [Ollama](https://ollama.com) for a local model.

### Highlights

- **Chats keep working in the background.** Start a new chat while another is still working; each chat keeps its own replies, tool cards and approvals.
- **More `@` mentions and 19 more `/` commands** that run when you press Enter (`/stop`, `/retry`, `/team`, `/model`, `/summarize`, ...).
- **Shift+Enter** for a new line, **middle-click scroll mode**, and a fix for the skills error "missing argument 'name'".
- **Blip** thinks, works, waits for your OK, listens, cheers and droops with the state of the chat; fewer visual glitches, cheaper to draw, and it can be made calm, smaller or switched off.
- **17 Craft apps** found automatically and checked against today's versions (PhotoCraft 0.21.0 ... Craft Anything 0.5.0, MaterialCraft 0.2.0 saves `.sbs`).

### Known limits

- Only Windows 11 has been used and tested. Please report macOS and Linux results.
- The OpenAI-compatible and Anthropic adapters follow the documented wire format but were not run against live APIs by the maintainers.
- Small local models are weak at planning and tool use.
